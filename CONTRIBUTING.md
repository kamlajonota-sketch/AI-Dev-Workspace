# Contributing

Thanks for helping improve AI-Dev-Workspace. Contributions should make the workspace safer, clearer, or more useful across different project types.

## Before opening a change
1. Read [AGENTS.md](AGENTS.md), [the workflow](docs/WORKFLOW.md), and [security guidance](docs/SECURITY.md).
2. Open an issue for substantial features or structural changes so the scope can be discussed.
3. Keep changes focused and tool-agnostic unless a tool-specific guide is clearly labeled.
4. Never add real credentials, personal data, or copyrighted material without permission.

## Make a change
- Use a branch for contributions when possible.
- Update relevant docs and templates.
- Keep examples generic, accurate, and safe to copy.
- Run `python scripts/validate_workspace.py` if Python is available.
- Review your diff for unrelated changes and secrets.

## Pull requests
Explain the problem, the change, verification performed, and any limitations. Do not claim tests passed unless they were actually run. Follow the repository pull request template.

## Scope
This repository provides reusable guidance and templates. It does not guarantee that generated code is correct or secure, and it does not provide or execute every AI tool's proprietary commands or hooks.
